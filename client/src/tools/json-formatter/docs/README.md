# JSON Formatter & Validator

Beautify, minify, and validate JSON directly in your browser.

## Features
- Indent size selection (2 spaces, 4 spaces, tabs).
- Error line indicator highlighting structural bugs.
- Minification output format.
- Instant copy-to-clipboard.

## Usage
1. Enter raw or malformed JSON in the input field.
2. Select formatting settings.
3. Click "Format" or "Minify".
4. Review validation errors or copy the result.
