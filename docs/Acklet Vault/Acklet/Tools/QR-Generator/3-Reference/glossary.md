# Glossary

- **EC (Error Correction Level)**: L/M/Q/H. Ability of QR to be read if damaged (7%/15%/25%/30% of code damaged)
- **QR Version**: 1–40. Larger numbers = more modules = more capacity
- **Capacity**: Max characters for given version + EC (alphanumeric mode)
- **Quiet Zone**: 4-module white margin around QR (spec requirement)
- **Module**: Single square (dark or light) in QR grid
- **Data URL**: Embedded image in URL format: `data:image/png;base64,...`
- **Contrast Ratio**: Measure of color difference (WCAG AA ≥ 4.5:1)
- **LCP (Largest Contentful Paint)**: Page load metric (target < 2.5s)
- **PNG**: Raster image format, lossless
- **Foreground**: Dark module color (usually black)
- **Background**: Light module color (usually white)
