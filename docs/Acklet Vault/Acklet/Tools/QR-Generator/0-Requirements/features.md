# Features

## Phase 1 (MVP)

### ✅ In Scope
- Single QR code generation
- 4 input types: Text, URL, Email, Phone
- Color customization (foreground + background)
- Size slider (100–2000px)
- Error correction selector (L/M/Q/H)
- Real-time preview + metadata
- PNG download
- Contrast warning for accessibility

### ❌ Out of Scope (Phase 2+)
- Logo upload
- Batch generation
- vCard / Wi-Fi input
- SVG / JPG / EPS output
- History / localStorage
- Templates
- Backend integration
- Analytics

## Phase 2

- Logo overlay customization
- Shape customization (modules, corners)
- Frames + CTA text
- Batch QR generation
- History tracking
- Pre-built templates
- SVG + JPG output
- More input types (vCard, Wi-Fi, SMS)

## Phase 3+

- Backend QR generation
- Shareable links
- Analytics dashboard
- Cloud storage
- Vector formats (EPS)
