# Barcode Generator — Standards & External Links

This document lists official technical specifications, RFCs, and related Acklet workspace resources.

---

## 1. Official Standards & Specifications

- [GS1 General Specifications Standard](https://www.gs1.org/standards/barcodes-epcrfid-id-keys/gs1-general-specifications) — Official standard for GTIN-13, GTIN-12, GTIN-8, ITF-14, and GS1 Application Identifiers.
- [GS1 Check Digit Calculation](https://www.gs1.org/services/check-digit-calculator) — Reference Modulo-10 checksum algorithm.
- [ISO/IEC 15417 (Code 128)](https://www.iso.org/standard/43896.html) — Standard for Code 128 symbol specification.
- [ISO/IEC 16388 (Code 39)](https://www.iso.org/standard/43897.html) — Standard for Code 39 symbol specification.
- [ISO/IEC 15420 (EAN/UPC)](https://www.iso.org/standard/46143.html) — Standard for EAN/UPC symbology.
- [International ISBN Agency](https://www.isbn-international.org/) — Specifications for ISBN-13 and ISBN-10 to 13 conversion.
- [W3C Web Barcode Detection API](https://wicg.github.io/shape-detection-api/#barcode-detection-api) — Specification for the native browser `BarcodeDetector` interface.
